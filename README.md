# 📝 Django To-Do List App

A simple **To-Do List web application** built using **Django** that allows users to manage their daily tasks efficiently.  
This project is designed as a **Beginner → Intermediate Django practice project** focusing on CRUD operations, authentication, and template inheritance.

---

## 🚀 Features

- User authentication (Login required)
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed using checkboxes
- Task deadline support
- ScrollSpy UI for task navigation
- Secure user-specific task handling

---

## 🛠 Tech Stack

- **Backend:** Django (Python)
- **Frontend:** HTML, Bootstrap 5
- **Database:** SQLite (default Django DB)
- **Authentication:** Django Auth System
